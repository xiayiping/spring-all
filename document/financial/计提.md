# 财务中的计提是什么概念

在财务中，**计提**是一个核心概念，简单说就是**提前记账**。凡是符合“本期已经发生，但钱还没实际收付”的情况，都需要计提。

它的理论基础是**权责发生制**——不看钱是否到账，只看权利义务是否在本期发生。

**举个直观例子：**
公司1月份的电费，2月份才交。那在1月底，虽然没付钱，但这笔费用已经发生了，就必须在1月份的账上**计提**这笔电费。分录是：
- 借：管理费用—电费
- 贷：应付账款

这样1月的利润表才真实反映了当月的成本，不会虚增利润。

**常见的计提场景：**

- **计提费用**：房租、水电费已发生但未付款；贷款利息按天产生，到期才付；年终奖虽明年发，但属于今年成本。
- **计提减值**：存货市价下跌、客户赖账不还的坏账、设备老旧不值钱了，都需要提前预估损失并记账。
- **计提折旧/摊销**：买设备花100万用10年，每个月计提折旧，把成本分摊到各期。

**和“预提”“待摊”的区别：**
- **预提**是计提的一种，专指先享受后付款的费用。
- **待摊**是先付款后享受，按受益期分摊，正好相反。

**为什么要计提？**
核心是让报表真实反映经营情况，遵循“不低估负债和费用”的谨慎性原则，防止利润虚高导致多交税或多分红，最终损害公司根基。

## 例子

在财务和会计中，“计提”的意思是：**根据权责发生制原则，对当期已经发生但尚未实际支付现金的费用或损失，预先计算并入账**。

简单说，就是把这期该承担的成本先“留出来”。核心目的有两个：

1.  **匹配原则**：让当期的收入和成本对应，准确计算利润。
2.  **避免利润虚高**：防止因未付款项导致账面盈利，但实际已欠债。

常见的计提项目包括：

-   **计提工资**：1月工资2月发，1月底要先计提这笔费用。
-   **计提折旧**：买设备花100万，分期摊销，每月计提一部分。
-   **计提税费**：1月产生的税，2月缴纳，1月底要计提。
-   **计提坏账准备**：预估可能有收不回的应收账款，提前计入损失。
-   **计提利息**：银行贷款利息按月结算，每月计提应付利息。

举个简单例子：
1月公司员工工资共10万元，2月15日才发放。

-   **1月底（计提）**：借记“管理费用”10万，贷记“应付职工薪酬”10万。显示1月已承担这笔费用。
-   **2月15日（发放）**：借记“应付职工薪酬”10万，贷记“银行存款”10万。此时只影响资产，不再计入费用。

通过计提，1月份的财务报表就能真实反映当月发生了10万元的人工成本。


# 计提就是让这部分发生能体现在当期的利润表吗

是的，你理解得很到位。

**计提最直接的目的，就是让这部分已经发生的成本或损失，能准确地反映在当期利润表里。**

拆开来看，它能达到三个关键效果：

-   **防止虚增利润**
    就像前面电费的例子，如果不在1月计提那10万元费用，当月利润就虚增了10万。这会导致公司错误地认为自己很赚钱，可能过早分红或扩张。

-   **遵循“收入成本匹配原则”**
    如果当月有收入，就必须把创造这笔收入所花费的成本，都算在当月。比如发了销售提成100万，但这笔提成对应的应收款可能变坏账，就需要计提一笔坏账准备，让风险和收益在同一期匹配。

-   **挤出报表水分**
    除了费用，更关键的是**资产减值损失**。比如高价进的存货，现在市价跌了，如果不计提跌价准备，报表上的资产就是虚的，得在利润表里确认一笔损失，把水分挤掉。

所以，**计提就是在资产和负债端先记上一笔，而它的最终落脚点，是通过“费用”或“损失”的形式，扣减当期利润**，让利润表展示最真实的经营成果。
